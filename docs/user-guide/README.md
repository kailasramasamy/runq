# runQ User Guide

> The non-finance, non-tech, "I just want to run my business" guide to runQ.

If you've never used accounting software before — or if you've only ever used Tally — this guide is for you. Read it once, end-to-end, and you'll be running your daily finance ops in runQ within an hour.

---

## Who this guide is for

- Business owners who don't have a full-time accountant
- Owners who use Tally but find day-to-day data entry painful
- Operations / sales / admin staff who need to raise invoices and record payments
- New employees being onboarded onto runQ

You do **not** need to know accounting jargon. We explain everything in plain English the first time it appears.

---

## Where runQ ends and Tally begins

runQ is built for **daily operations**:
- Raising invoices, recording payments, entering bills, reconciling your bank
- Seeing how much cash you have, who owes you, who you owe
- Finding any transaction in seconds

runQ is **not** built for **statutory compliance**:
- We don't file GST returns (GSTR-1, GSTR-3B)
- We don't generate e-invoices or e-way bills
- We don't produce statutory financial statements for the ROC

For all of those, your CA still uses Tally. The bridge is **Tally Export** — once a month, you push all your runQ transactions into Tally as XML, and your CA does the rest. See [Recipe 11](./recipes/11-export-to-tally.md).
